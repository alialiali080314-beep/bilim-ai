# BilimOS на iPhone — Руководство UTM

## Что такое UTM

**UTM** — приложение для iOS, которое запускает виртуальные машины с помощью QEMU.  
ARM64-версия BilimOS работает **нативно** на процессорах Apple Silicon (A-серия), без эмуляции.

---

## Шаг 1 — Установить UTM на iPhone

Скачать из **App Store**: поиск `UTM` → приложение с синим логотипом.

> Альтернатива: UTM SE (тоже App Store) — ограниченная бесплатная версия.

Системные требования:
- iOS 14+ / iPadOS 14+
- iPhone 6s и новее (рекомендуется iPhone 12+)
- 4+ ГБ свободного места

---

## Шаг 2 — Скопировать ISO на iPhone

После сборки ISO (`./build.sh`) файл будет здесь:
```
iso-build/bilimos-1.0-arm64.iso
```

**Способ 1 — через iCloud Drive:**
1. Загрузить `bilimos-1.0-arm64.iso` в iCloud Drive
2. На iPhone: Файлы → iCloud Drive → найти ISO

**Способ 2 — через кабель (Finder / iTunes):**
1. Подключить iPhone к Mac/ПК
2. В Finder выбрать iPhone → Файлы → UTM
3. Перетащить ISO в папку UTM

**Способ 3 — через AirDrop (с Mac):**
1. На Mac: правая кнопка на ISO → Поделиться → AirDrop
2. На iPhone: принять файл → Сохранить в UTM

---

## Шаг 3 — Создать виртуальную машину в UTM

1. Открыть **UTM** на iPhone
2. Нажать **+** → **Virtualize** (не Emulate!)
3. Выбрать **Linux**
4. Нажать **Browse** → найти `bilimos-1.0-arm64.iso`
5. Настройки:

| Параметр | Значение |
|----------|----------|
| Architecture | ARM64 (aarch64) |
| RAM | 2048 MB (минимум), 4096 MB (лучше) |
| CPU Cores | 2–4 |
| Storage | 16–32 GB |
| Display | VirtIO |
| Boot | CD/DVD (ISO) |

6. Нажать **Save**

---

## Шаг 4 — Запустить BilimOS

1. В UTM нажать **Play** (▶) на созданной ВМ
2. Дождаться загрузки GRUB-меню
3. Выбрать **«BilimOS 1.0 Live»** → Enter
4. Система загрузится (~2–5 минут)

**Логин в live-режиме:**
- Логин: `bilim`
- Пароль: `bilimos`
- Автовход включён — рабочий стол откроется сам

---

## Шаг 5 — Установка (опционально)

Если хочешь установить BilimOS внутри виртуального диска UTM:

1. На рабочем столе: открыть **«Установить BilimOS»**
2. Или в терминале: `sudo bilimos-installer`
3. Следовать инструкциям:
   - Выбрать диск: `vda` (виртуальный диск UTM)
   - Ввести имя пользователя и пароль
   - Подождать ~5-10 минут
4. После установки: в UTM убрать ISO из настроек ВМ → перезагрузить

## Советы по производительности

| Совет | Описание |
|-------|----------|
| Virtualize, не Emulate | ARM64 ISO работает нативно — намного быстрее |
| RAM 4096 MB | GNOME требует минимум 2 ГБ, 4 ГБ комфортно |
| Зарядка | Держи iPhone на зарядке — ВМ потребляет много энергии |
| Display Scale | В UTM Settings → Display Scale = 2x для Retina |
| Клавиатура | Подключи Bluetooth-клавиатуру для удобной работы |

|----------|-------------|
| Показать/скрыть клавиатуру | Кнопка клавиатуры в тулбаре UTM |

## Возможные проблемы

**Чёрный экран при загрузке:**
- В UTM → Settings → Display → включить VirtIO-GPU

**GNOME не запускается:**
- В меню GRUB выбрать «Безопасный режим» (nomodeset)

**Медленно работает:**
- Убедись что выбран режим **Virtualize**, а не Emulate
- Уменьши разрешение: Settings → Display → 1280×720

**Нет звука:**
- В UTM добавить устройство: Devices → Sound → Intel HDA
